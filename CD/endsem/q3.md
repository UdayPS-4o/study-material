**ii. What is function overloading?**
**Answer:** Function overloading is a feature in programming languages where multiple functions can have the same name but differ in the number, type, or order of their parameters. The compiler determines which specific function to call based on the arguments provided during the function invocation.

**iii. What is type conversion? Differentiate between implicit and explicit type conversion.**
**Answer:**
Type conversion is the process of converting a value of one data type into another data type.

| Feature | Implicit Type Conversion (Coercion) | Explicit Type Conversion (Casting) |
| :--- | :--- | :--- |
| **Definition** | Automatically performed by the compiler without programmer intervention. | Manually specified by the programmer using a cast operator. |
| **Safety** | Usually safe and involves promoting smaller types to larger ones (e.g., `int` to `float`) to prevent data loss. | Can lead to data loss or truncation if not careful (e.g., `float` to `int`). |
| **Syntax** | No special syntax required. | Requires a cast operator, e.g., `(int) 3.14`. |
| **Example** | `float x = 5;` (integer 5 is implicitly converted to 5.0) | `int y = (int) 5.8;` (float 5.8 is explicitly converted to 5) |

**iv. Describe various storage allocation strategies and their advantages and disadvantages.**
**Answer:**
There are three main storage allocation strategies used by compilers:

1. **Static Storage Allocation:**
   - Memory is allocated at compile-time and remains fixed throughout program execution. Variables are bound to absolute addresses.
   - **Advantages:** Fast execution as there is no runtime overhead for allocation/deallocation. Easy to implement.
   - **Disadvantages:** Cannot support dynamic data structures (like linked lists), recursion is not possible (as local variables share the same memory location), and memory size must be known at compile time, leading to potential waste.

2. **Stack Storage Allocation:**
   - Memory is allocated on a Last-In-First-Out (LIFO) basis using a call stack. When a function is called, an activation record (stack frame) is pushed onto the stack containing local variables and return addresses. When it returns, the frame is popped.
   - **Advantages:** Naturally supports recursion and dynamic allocation of local variables. Memory is reused efficiently.
   - **Disadvantages:** Cannot handle variables whose lifetimes exceed the function call (e.g., returning a pointer to a local variable). Size of local variables must often be known at compile time.

3. **Heap Storage Allocation:**
   - Memory is allocated dynamically at runtime from a pool of free memory (the heap). It can be allocated and freed in any order.
   - **Advantages:** Highly flexible. Supports dynamic data structures (trees, graphs, linked lists) whose size is unknown at compile time. Variables can live beyond the scope of the function that created them.
   - **Disadvantages:** Slower due to the overhead of managing the memory pool (allocation, deallocation, garbage collection). Prone to memory fragmentation and memory leaks if not managed correctly.

**iv. Write short notes on the following terms-**
**a) Purpose of error detection and recovery in a compiler**
**Answer:**
**Error Detection and Recovery:**
- **Purpose:** A compiler must not only translate valid programs but also handle invalid ones gracefully. The primary purposes are to detect errors early, report them clearly to the programmer (with line numbers and context), and recover from them to continue parsing.
- **Recovery:** Continuing the compilation process after encountering an error allows the compiler to find subsequent errors in the same pass, saving the programmer time. Common recovery strategies include:
  - **Panic Mode:** Discarding input tokens until a synchronizing token (like a semicolon or bracket) is found.
  - **Phrase-Level Recovery:** Performing local corrections on the remaining input (e.g., inserting a missing semicolon).
  - **Error Productions:** Adding special rules to the grammar to anticipate common mistakes and handle them as valid structures for error reporting.

**b) Polymorphic functions**
**Answer:**
**Polymorphic Functions:**
- Polymorphism refers to the ability of a function to process data of multiple types.
- A polymorphic function is one whose code can be applied to arguments of different types, behaving appropriately for each type.
- **Types of Polymorphism:**
  - **Ad-hoc Polymorphism:** Includes function overloading (same name, different signatures) and operator overloading.
  - **Parametric Polymorphism:** Functions that are written generically without specifying exact types, often using type variables (e.g., Templates in C++, Generics in Java). This allows the same logic to apply to any type.
  - **Subtype Polymorphism (Inclusion):** Achieved via inheritance in OOP, where a function expecting a base class can accept any derived class object (e.g., virtual functions overriding).
