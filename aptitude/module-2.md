## 1. Mixtures

### Core idea
Always track each component **separately** (e.g. milk vs water in liters), THEN take ratio.

### Q1. 36 L mix milk:water = 3:1; add 15 L milk → new ratio
- Milk = 3/4 × 36 = 27; Water = 9.
- New milk = 27 + 15 = 42; water = 9.
- **42 : 9 = 14 : 3**.

### Q2. 25 L, acid:water = 4:1; add 3 L water → new ratio
- Acid = 20; water = 5 + 3 = 8.
- **20 : 8 = 5 : 2**.

### Q3 & Q4. Two equal vessels mixed
> If two vessels of equal volume have ratios a:b and c:d, after mixing:
> Final milk : water = (a/(a+b) + c/(c+d)) : (b/(a+b) + d/(c+d))

**Q3.** 3:7 and 7:9.
- Milk fraction: 3/10 + 7/16 = 24/80 + 35/80 = 59/80.
- Water: 7/10 + 9/16 = 56/80 + 45/80 = 101/80.
- **Milk : Water = 59 : 101**.

**Q4.** 3:5 and 3:1.
- Juice: 3/8 + 3/4 = 3/8 + 6/8 = 9/8.
- Water: 5/8 + 1/4 = 5/8 + 2/8 = 7/8.
- **Juice : Water = 9 : 7**.

### The Alligation rule (lifesaver for averages-of-mixtures)
```
       Cheap                Dear
         \                  /
          \                /
           Mean (average)
          /                \
         /                  \
   (Dear − Mean)      (Mean − Cheap)
```
Ratio of cheap : dear = (Dear − Mean) : (Mean − Cheap).

### Q5. Boys avg 70 kg, girls 60 kg; class avg 64 kg → Boys:Girls?
- Alligation: (64 − 60) : (70 − 64) = 4 : 6 = **2 : 3**.

## 2. Averages

### Core formula
> **Sum = Average × Count**

### Q6. 100 students avg 34; first 49 avg 34; last 50 avg 32 → weight of 50th
- Total = 100 × 34 = 3400.
- First 49 sum = 49 × 34 = 1666.
- Last 50 sum = 50 × 32 = 1600.
- 50th = 3400 − 1666 − 1600 = **134 kg** *(answer per paper — re-check question wording; arithmetic from the given numbers gives 134)*.

### Q7. avg(A,B,C) = 65; avg(A,B) = 63.5; avg(A,C) = 67.5 → A
- A+B+C = 195; A+B = 127; A+C = 135.
- Trick: (A+B) + (A+C) − (A+B+C) = A → 127 + 135 − 195 = **67 kg**.

### Q8. Avg age husband+wife when child born = 27 (sum = 54). Now avg of 3 = 21 (sum = 63).
- Sum increased by 63 − 54 = 9, but each parent aged by the same amount t → 2t + child = 9.
- Child's present age = 9 − 2t. We need t = age of child too (years since birth).
- So child's age + 2×(child's age) = 9 → child = **3 years**.

**Trick:** for "avg age was X when Y born, now avg is Z including the new person", solve via sum equation.

## 3. Time–Speed–Distance (TSD)

### Core
> **Distance = Speed × Time**

Unit converter: **1 km/h = 5/18 m/s**, and **1 m/s = 18/5 km/h**.

### Q9. 60 km/h in 50 min; reduce time to 20 min → new speed
- Distance = 60 × 50/60 = 50 km.
- New speed = 50/(20/60) = 50 × 3 = **150 km/h**.

**Shortcut (inverse ratio):** speed ∝ 1/time for same distance. New speed = 60 × 50/20 = **150**.

### Q10. Train at 63 km/h crosses pole in 24 s → length
- Speed = 63 × 5/18 = 17.5 m/s.
- Length = 17.5 × 24 = **420 m**.

### Q11. At 60% of usual speed → 36 min late. Usual time?
- Speed ratio 60:100 = 3:5 → time ratio 5:3.
- Extra time = 5 − 3 = 2 parts = 36 min → 1 part = 18.
- Usual time = 3 × 18 = **54 min**.

### Q12. Two platforms problem
> When a train crosses a platform of length L in time T: **L + train = speed × T**.

- 400 + l = s × 50, 600 + l = s × 60. Subtract: 200 = 10s → s = 20 m/s.
- 400 + l = 1000 → l = **600 m**.
- Speed in km/h = 20 × 18/5 = **72 km/h**.

### Q13. At 40 km/h → 25 min late; at 50 km/h → 10 min late. Distance?
- Let on-time = T (hr). Then D/40 = T + 25/60 and D/50 = T + 10/60.
- Subtract: D/40 − D/50 = 15/60 = 1/4 → D(1/40−1/50) = 1/4 → D × 1/200 = 1/4 → **D = 50 km**.

**Trick for "late twice" problems:** D × (1/v₁ − 1/v₂) = (t₁ − t₂) in hours.

## 4. Time & Work

### Core
> If A does work in `a` days, A's 1-day work = **1/a**.
> Combined 1-day work = sum of individuals.

### Q14. A+B = 18d, B+C = 24d, A+C = 36d → all three together
- Add: 2(A+B+C) = 1/18 + 1/24 + 1/36.
- LCM 72: 4/72 + 3/72 + 2/72 = 9/72 = 1/8.
- A+B+C 1-day = 1/16 → **16 days**.

### Q15. A=6, B=8, C=12. All work 2 days, then only B → total days
- 1-day work: 1/6 + 1/8 + 1/12 (LCM 24) = 4/24 + 3/24 + 2/24 = 9/24 = 3/8.
- 2 days = 6/8 = 3/4 done. Remaining = 1/4.
- B alone needs (1/4)/(1/8) = 2 more days.
- Total = 2 + 2 = **4 days**.

### Q16. A=8, B=12; A leaves 2 days before completion. Total days?
- Say total = T days. B works all T; A works (T−2).
- (T−2)/8 + T/12 = 1 → multiply by 24: 3(T−2) + 2T = 24 → 5T = 30 → **T = 6 days**.

### Q17. A=10, B=12, C=15; B leaves 3 days before end
- 1-day rates (LCM 60): A=6, B=5, C=4 units/day. Total work = 60.
- Last 3 days: only A+C = 10/day × 3 = 30. Remaining 30 done by all → 30/15 = 2 days.
- Total = 2 + 3 = **5 days**.

### Q18. A=10,B=12,C=15. C leaves after 3 days; B leaves 4 days before end
- Rates (LCM 60): A=6, B=5, C=4. Total = 60.
- Let total = T days. C works first 3 days, B works first (T−4) days, A works all T.
- 6T + 5(T−4) + 4(3) = 60 → 6T + 5T − 20 + 12 = 60 → 11T = 68 → **T ≈ 6.18 days** (≈ 7 days practically).

**Trick:** always set total work = LCM of given days. Numbers stay whole.

## 5. Mensuration (Geometry)

### Formulas you must know

| Shape | Formula |
|---|---|
| Circle area | πr² |
| Circle circumference | 2πr |
| Triangle (2 sides + angle) | ½ ab sin C |
| Trapezium | ½ (sum of parallel sides) × height |
| Parallelogram | base × height |
| Cylinder volume | πr²h |
| Cylinder TSA | 2πr(r+h) |

### Q19. Outer:inner circumference = 5:4, path width 50 m → inner radius
- 2πR : 2πr = 5:4 → R = 5k, r = 4k. Path = R − r = k = 50.
- r = **200 m**.

### Q20. Triangle sides 4, 5; angle 45°
- Area = ½ × 4 × 5 × sin 45° = 10 × (√2/2) = **5√2 ≈ 7.07 cm²**.

### Q21. Cylinder r:h = 3:4; V = 38808 (π = 22/7) → diameter
- r = 3k, h = 4k. V = π(3k)²(4k) = 36πk³.
- 36 × 22/7 × k³ = 38808 → k³ = 38808 × 7 / (36 × 22) = 343 → k = 7.
- r = 21 → **d = 42 cm**.

### Q22. Trapezium: distance between parallel sides 18, area 1188 → sum of parallel sides
- Area = ½ × sum × h → 1188 = ½ × sum × 18 → sum = **132 cm**.

### Q23. Parallelogram: base = 2 × height, area = 338 → height
- 2h × h = 338 → h² = 169 → h = **13 cm**.

## 6. Permutations & Combinations

### Core rules
- **Permutation** (order matters): P(n,r) = n! / (n−r)!
- **Combination** (order doesn't): C(n,r) = n! / [r!(n−r)!]
- **Arrangement of n letters with repeats** of p, q, …: n! / (p! q! …)

### C(n,r) quick values
```
C(n,0)=1   C(n,1)=n   C(n,2)=n(n−1)/2   C(n,n)=1
C(n,r) = C(n, n−r)   ← symmetry
```

### Q24. Choose team of 5 from 4 girls + 5 boys, ≥ 2 girls
- Cases: (G2,B3), (G3,B2), (G4,B1).
- C(4,2)·C(5,3) + C(4,3)·C(5,2) + C(4,4)·C(5,1)
- = 6·10 + 4·10 + 1·5 = 60 + 40 + 5 = **105**.

### Q25. 'DESIGN' — vowels at two ends
- Vowels in DESIGN: E, I → 2 vowels. Place at ends: 2! = 2 ways.
- Middle 4 letters: 4! = 24.
- Total = 2 × 24 = **48**.

### Q26. 'RECTITUDE' — vowels together
- Letters: R,E,C,T,I,T,U,D,E (9 letters). Vowels = E,I,U,E (4). Repeats: T(2), E(2).
- Treat 4 vowels as 1 block → 6 units. Arrange = 6!/2! (T repeats).
- Vowels inside block: 4!/2! (E repeats).
- Total = 360 × 12 = **4320**.

### Q27. Group of 5 men + 2 women from 7M, 3W
- C(7,5) × C(3,2) = 21 × 3 = **63**.

### Q28. 5 Blue, 4 Red, 3 Green socks — choose 4
- Total = C(12,4) = **495**. *(if colors don't matter beyond count, list cases — but usually total combinations is asked)*

### Q29. 'ADITYA' (6 letters, A repeats twice)
- 6!/2! = 720/2 = **360**.

### Q30. 'RUMOUR' (6 letters: R×2, U×2)
- 6!/(2!×2!) = 720/4 = **180**.

## Speed tips for Module 2

1. **Mixture trick:** for "two equal containers" problems, just sum fractions of milk and water.
2. **TSD with late times:** D = (t₁−t₂)·v₁v₂ / (v₂−v₁). Memorize once, save 1 minute every time.
3. **Work problems:** total work = LCM of days → keeps every fraction whole.
4. **P&C with repeats:** always divide by the factorial of each repeated letter's count.
5. **Permutation vs Combination:** ask yourself "Does the order matter?". If yes → P, if no → C.
