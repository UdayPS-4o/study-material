# Scientific Aptitude — Study Guide

A complete, easy-to-learn guide built from the IPS Academy Scientific Aptitude assignments. Every concept is explained with **the trick**, **why it works**, and a **worked example** from the actual paper.

## How to use this guide

1. Read the **Concept** box first — that's the "why".
2. Memorize the **Trick** (usually a one-line formula or shortcut).
3. Work through the **Solved problems** — they are the exact assignment questions.
4. The **Speed tips** at the end of each module are gold for exam day.

## Golden rules across all modules

- **Don't compute big numbers.** Convert % to fractions (25% = 1/4, 20% = 1/5, 12.5% = 1/8). Math gets 10× faster.
- **Assume convenient numbers.** When the question gives only ratios/%, assume the total = 100 (or LCM of denominators). Answers always work out.
- **Draw before you solve.** Direction, seating, blood-relation problems collapse the moment you sketch them.
- **Check the answer choices first.** Many problems are solvable by plugging options in faster than algebra.
